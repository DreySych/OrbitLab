# OrbitLab
ORBIT LAB — это доступный веб-инструмент для моделирования и визуализации орбитальной динамики. Проект решает проблему разрыва между абстрактными формулами и реальным пониманием космического полета. Пользователь может настраивать начальные условия (скорость, угол, массы 2-3 небесных тел) и мгновенно видеть рассчитанную траекторию.
